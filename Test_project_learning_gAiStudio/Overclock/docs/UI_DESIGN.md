# OVERCLOCK — UI/UX Design

## Design Philosophy
A rigorous **retro-futuristic military operating system** interface.
- No rounded cards or soft pastel gradients.
- Sharp 0px/2px corner radiuses, technical 1px borders, grid matrix backdrop, and tactical monospace typography.
- Real-time reactive gauges that change color and pulse with rising system heat.
- Glitch & chromatic aberration effects during Hacker debuffs or Meltdown states.
- High-contrast HUD designed to keep the central combat viewport unobstructed.
