# OVERCLOCK — Level & Mission Design

## Mission Structure & Pacing Curve
1. **MISSION 01: BOOT / TARGET ACQUISITION**
   - Threat Level: LOW
   - Arena: Low-intensity facility testing floor.
   - Enemies: Calibration Drones (HP 26, damage 8, bullet speed 290).
   - Objective: Calibrate movement, aiming, and plasma firing in an approachable combat space.
2. **MISSION 02: THERMAL CONTAINMENT**
   - Threat Level: MODERATE
   - Arena: Reactor vent chamber.
   - Enemies: Drones + Chargers (HP 70, generous 1.15s visual windup telegraph for reliable dash dodging).
   - Objective: Master heat management and timed dash evasion.
3. **MISSION 03: OVERRIDE INITIATION**
   - Threat Level: HIGH
   - Arena: Overclock testing bay.
   - Enemies: Fortified Turrets (HP 130, damage 11, 2.8s firing cycle) + Drones + Chargers.
   - Objective: Utilize Overclock to punch through high-durability fortified turrets while avoiding excessive thermal load.
4. **MISSION 04: POWER ROUTING TRIAL**
   - Threat Level: HIGH
   - Arena: Grid Distribution Node.
   - Enemies: Energy Leeches (drain rate 8 EP/s, tether distance 300) + Chargers + Turrets.
   - Objective: Dynamic power rerouting between Shield, Cooling, Engine, and Weapons to counter capacitor drain.
5. **MISSION 05: SYSTEM BREACH**
   - Threat Level: EXTREME
   - Arena: Core Cyberwarfare Hub.
   - Enemies: System Hackers (HP 75, 5.2s cooldown, 2.8s hack duration) + Mixed enemy defense waves.
   - Objective: Prioritize threat elimination while resisting UI and control glitches.
6. **FINAL ENCOUNTER: THE ADMINISTRATOR**
   - Threat Level: CRITICAL
   - Arena: Central AI Mainframe Core.
   - Structure: 4-phase facility boss with destroyable subsystems (Matrix Shield, Gatling Array, Thruster Relay, Mainframe Core 1100 HP) and Overclock execution phase.
7. **SIMULATION: ENDLESS OVERDRIVE**
   - Post-Campaign Endless Mode: Infinite escalating waves with randomized rogue mutations and dynamic operator telemetry.
