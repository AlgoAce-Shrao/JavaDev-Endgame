# OVERCLOCK — Tech Stack & Dependencies

## Core Technologies
* **Language**: TypeScript 5.8+ (Strict type safety, strong interfaces).
* **Renderer**: HTML5 2D Canvas Context (Optimized batch rendering, zero heavy external canvas engine overhead, custom particle and lighting pipeline).
* **UI Layer**: React 19 + Tailwind CSS (Military OS HUD overlays, reactive technical telemetry).
* **Icons**: `lucide-react` (Tactical military icons).
* **Motion**: `motion/react` (Interface transitions).
* **Audio Engine**: Web Audio API Procedural Synthesizer (OscillatorNode, BiquadFilterNode, Convolver/GainNode for zero-dependency sound synthesis).
* **Build System**: Vite 6.
